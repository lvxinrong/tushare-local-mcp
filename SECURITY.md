# Security Policy

## Supported Versions

The project is in early development. Please use the latest `main` branch.

## Reporting a Vulnerability

Do not open a public issue for leaked tokens, credential handling problems, or
other security-sensitive reports. Contact the maintainer privately first.

## Token Handling

`TUSHARE_TOKEN` should be supplied through `.env` or environment variables.
Never commit `.env` or hard-coded tokens.
